# Start

These pages take you from deciding whether discern fits to adding your first reviewed change to your project. Your agent does the setup work. You answer the questions only you can answer, and you decide which changes join your project.

## Choose your starting point

- [Evaluate discern](evaluate-discern.md) if you're still deciding. It shows what discern does for you, what it asks of you, and what stays yours if you remove it.
- [Install and set up discern](installation-and-setup.md) when you're ready. You install one program, your agent sets up the project, and you review the result.
- [Make and review your first change](first-real-change.md) to try the everyday workflow on a small change you can see.
- [After setup](after-setup.md) when you want to know what the new files do and where to make changes later.

You need a project, a supported coding agent, and a computer running macOS or Linux. On Windows, discern runs inside WSL 2. [Platforms and providers](../30-reference/platforms-and-providers.md) lists the supported systems and coding tools.

## Once you're ready to work

[Finish and land a change](../10-guides/finish-and-land-a-change.md) shows the everyday loop. You describe what you want, your agent makes and checks the change, and you review what comes back. [Proof](../20-understand/proof.md) shows how to read the record of those checks.

You don't need to set up every feature before your first task. Turn to the other [guides](../10-guides/README.md) as you need them.
