---
summary: "◮ discern v1.4: run fewer checks at once on small CI runners and see where a slow run spends its time."
codename: "Ridgeline"
---

If your tests pass locally but time out on a CI runner with little memory, you can now set `DISCERN_GATE_CONCURRENT_COMMANDS=2` to run at most 2 gate commands at once. Each command gets its full time limit once it starts. [Run the gate in CI](https://discern.sh/docs/guides/run-the-gate-in-ci)

To investigate a slow run, set `DISCERN_ENGINE_TIMING=1`. The logbook then shows when each step and command started and how long it took. On WSL 2, `discern doctor` also warns when your checkout sits on a slow Windows mount.

When you approve a new limit for a standard, the proposed limit now includes the margin you configured. After the change lands, CI can report which limits changed and run your checks against the new limits.

The [discern homepage](https://discern.sh/) now lets you explore what each feature does for your project. Under the hood, discern skips the contents of ignored directories and reuses Git results within a run.
