"**Shoreline**" is discern's v1.3.0 release, focused on working alongside the agent tools your project already uses, such as a framework's agent kit or a skill installer.

## Keep the agent tools you already use

- Other tools' skills stay put. discern manages only the skills it installed.
- When a refresh replaces another tool's lines in an agent file such as `AGENTS.md`, discern lists them and how to keep them.
- Instruction sources compile in the order you list them, so you decide where a tool's rules sit among yours.

A new guide, [Use discern alongside other agent tools](https://discern.sh/docs/guides/use-discern-alongside-other-agent-tools), shows how to set it all up.

This release also brings clearer setup messages and fixes for reliability.
