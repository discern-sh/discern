"**Snowline**" is discern's v1.2.0 release, focused on a redesigned desk: the interactive view of every task in progress, which opens when you run `discern` in your main checkout.

## A redesigned desk

- The desk opens on a Commands row. Its panel lists what you can do from there, such as start a task, read the manual, or check for updates, with each command's key.
- Tasks are grouped by who moves next: Ready for review, Needs attention, Working, Approved to land, and Idle. A details panel follows your selection with the task's checks, how far the trunk has moved, its changes, and its next step, which Enter runs.
- The desk, `discern status`, and `discern enter` describe each task in the same words and marks, and green marks only work that can land.
- Every change opens a review that leads with what it will do, such as how far the trunk has moved and what lands after it. The changes, the plan, and the exact command are one key away.
- Checks and landings run inside the desk with live progress, so you can keep working with other tasks while they run. Session activity lists every command the desk ran and how it ended.
- The manual opens inside the desk, and `discern docs` uses the same browser, with contents, search, and Back.

## Other fixes and changes

- `discern done` keeps going when its terminal stops reading output for a while, instead of crashing. If another run has taken over in the meantime, `done` ends as cancelled and asks you to run it again.
- `discern doctor` and other commands wrap long advice to the width of your terminal.
- A new task with no commits reads Empty when the trunk moves, and a branch whose commits continue in another task stays Contained however long it sits idle.
- A landing that stops after the trunk has moved says what landed, and the desk offers recovery steps for an interrupted landing.
- The CI guide now asks you to leave GitHub's **Require linear history** rule off for your trunk, because a task that lands after the trunk has moved reaches it through a merge commit.
- `discern status --json` rows gain `state` and `group` fields, and `discern progress` reports each step of a plan as it runs.
