---
summary: "Separate workspaces for coding tasks, shared instructions for agents, and project checks before changes land."
---

Each coding task gets its own workspace (a Git worktree), so agents can work in separate checkouts. The project's quality gate runs its configured checks and records Proof for the committed change. Changes land with the owner's approval or permission already recorded by the project.

The interactive desk shows your tasks in progress. You can also use discern through its CLI or MCP integrations. Shared agent instructions, reusable skills, project documentation, and quality standards carry your project's working rules from task to task.

The manual and setup templates are built in, so they work offline. To update an existing project after installing discern, preview its upgrade and review the proposed changes before applying them.
