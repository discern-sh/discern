# Art sources

The complete `art/` tree is part of the repository.

`art/terminal/` is product source. Its registries and renderers supply discern's terminal figures, animations, capture fixtures, and the maintainer gallery. Run `deno task art` for the terminal-safe gallery or `deno task terminal:review` for the loopback review surface.

`art/browser/` is a loopback-only development gallery for visual studies. It is absent from the public site and is not a product interface, public asset library, or statement of future direction.
