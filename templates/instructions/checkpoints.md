{{#if has_checkpoints}}## Checkpoints

Configured checkpoints serve a question which requires your judgment when a matching change completes. `discern_status` and `discern_prepare` name detected checkpoints early. On `discern_done`, use `met` only for a satisfied served question; otherwise use `unmet` with a short, owner-relevant, secret-free tradeoff. A variance requires the owner to explicitly accept the exact declared-unmet set; grants never cover one.{{/if}}
